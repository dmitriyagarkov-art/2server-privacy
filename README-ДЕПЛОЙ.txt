VPN-ГАЙД + УСТАНОВЩИК — как выложить
====================================

Что внутри:
  index.html     — страница-гайд (Vercel отдаёт её как сайт)
  images/        — скриншоты к шагам
  install.sh     — установщик, который запускается ОДНОЙ командой
  vercel.json    — чтобы install.sh отдавался как текст (не скачивался)

--------------------------------------------------
ШАГ 1. Кладём на GitHub
--------------------------------------------------
1) Заводим аккаунт на github.com (если нет).
2) New repository → имя латиницей (напр. dm-setup) → Public → Create.
3) Add file → Upload files → перетаскиваем СЮДА всё содержимое этой папки
   (index.html, папку images, install.sh, vercel.json) → Commit changes.

--------------------------------------------------
ШАГ 2. Подключаем к Vercel
--------------------------------------------------
1) Заходим на vercel.com, входим через GitHub.
2) Add New → Project → Import наш репозиторий → Deploy.
3) Vercel выдаст адрес вида https://dm-setup.vercel.app
   (можно потом привязать свой домен в Settings → Domains).

--------------------------------------------------
ШАГ 3. Финальная команда
--------------------------------------------------
После деплоя установщик будет доступен по адресу:
   https://ВАШ-АДРЕС/install.sh

А команда для пользователей (её вставляем в Шаг 6 гайда вместо ВАШ_ДОМЕН):
   bash -c "$(curl -fsSL https://ВАШ-АДРЕС/install.sh)"

Пришлите мне ваш итоговый адрес Vercel — я подставлю его в гайд, добавлю
скрин терминала, и это будет финал.

--------------------------------------------------
Осталось доделать в гайде (index.html):
  • ВАШ_ДОМЕН в команде Шага 6  → ваш адрес Vercel
  • ССЫЛКА_НА_ДОСТУП (шапка + CTA) → канал «ИИ на практике»
  • ССЫЛКА_НА_ОТЗЫВЫ → отзывы
  • images/10-terminal.jpg → скрин терминала (пришлёте)
